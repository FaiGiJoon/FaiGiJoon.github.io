About

Helping people through technology

I'm a System and Security Engineer in the Netherlands, specializing in secure infrastructure, network automation and system administration. At a trusted company, I configure secure network infrastructure with MikroTik, build API automation to optimize device settings, and look after the security of a wide range of devices across the Netherlands.

Before that, I was the central hub for an enterprise Google Workspace migration at Prosus and helped build out the infrastructure for the Prosus AI House. I kept mission-critical warehouse systems running at FedEx Logistics, and taught networks, Windows Server and cybersecurity to MBO Level 4 students at ROC van Amsterdam.

My interest in tech started with Pokémon Platinum and the DeSmuME emulator. Figuring out how an emulator worked was my lightbulb moment, and by 13 I was hooked on computers. In 2015 I did my first IT internship, building and refurbishing PCs and setting them up with the brand-new Windows 10. Seeing someone's "slow" computer feel new again is what made me want to help people through technology.

In my own time I build and share open-source tools in Python and TypeScript, focused on local LLM integrations, real-time email security and secure network routing. Long term, I want to build automation software that helps hospitals around the world.
